# Security

To report a vulnerability in Marko, use
[Report a vulnerability](https://github.com/Den1al/marko/security/advisories/new) on GitHub. The
report is private until a fix is out. Please do not open a public issue for it.

Only the latest release is supported. What Marko does and never does on behalf of a document is
described in [docs/security.md](docs/security.md).
